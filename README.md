# sharingSCiML

## PPTC_DOE_portable
Portable kit for a 128-run OpenFOAM v2412 design of experiments on the PPTC VP1304 propeller in
open water (factors: advance coefficient J, blade pitch change, shaft speed), for building
scientific-ML surrogates. Start with [`PPTC_DOE_portable/README.md`](PPTC_DOE_portable/README.md);
pipeline status is in [`PPTC_DOE_portable/DOE_INFO.md`](PPTC_DOE_portable/DOE_INFO.md).
